## 当前能力

该脚本搜索卤素层法向、沿法向稳健分层，并根据同层最近六邻居的 `psi6`、`psi4` 和径向距离变异系数给出硬判定；同时把中心晶胞内的非卤素原子按局部几何近似归为四面体或八面体配位。

当前正式输出没有保存逐中心 `psi6/psi4` 的统计分布、层间距和堆叠注册关系。所谓四/八面体“占据率”也尚未建立在显式间隙枚举之上。因此，未经改造和校准，不应把该脚本的布尔输出或占据率直接用于论文机理结论。

详细的算法审计、推荐特征、数据主键和验证方案见：

- `docs/TRIANGULAR_LATTICE_FEATURES.md`

## 使用边界

- 不要覆盖或修改 `t23_reference.py`；需要开发时新建正式实现并记录来源哈希。
- 不要把输出按化学式连接到训练表，应按唯一 `cif_file/material_id` 连接。
- 不要把 `coord=6` 解释为独立测得的六配位数；当前代码是直接选最近六邻居。
- 不要把局部四/八面体配位计数写成真实空位数。
- 参数阈值需要人工标注结构和受控畸变结构校准。
- 新模型、特征表和图件使用独立目录，不覆盖当前 ExtraTrees 模型与历史图 2。
